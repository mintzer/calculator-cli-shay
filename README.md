# Calculator CLI

A very simple Python 3.12 CLI calculator.

## Usage

```bash
# Using the installed console script
calc_3_12 add 5 3    # Output: 8.0
calc_3_12 sub 10 4   # Output: 6.0
calc_3_12 mul 6 7    # Output: 42.0
calc_3_12 div 20 4   # Output: 5.0

# Direct execution (for development)
python calculator.py add 5 3    # Output: 8.0
python calculator.py sub 10 4   # Output: 6.0
python calculator.py mul 6 7    # Output: 42.0
python calculator.py div 20 4   # Output: 5.0
```
